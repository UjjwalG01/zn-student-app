## Conventions to adopt (verified in source)
- Errors: NestJS HTTP exceptions (`BadRequestException('A valid tenantId is required')` etc.) → normalize in central client (401→refresh, 403→permission-denied UI, 400→form errors).
- Pagination/filtering: query-param style per attendance controller; confirm page-token vs offset per endpoint during Phase 3 contract verification.
- Entitlement gating: `TenantEntitlementGuard` + `@RequireEntitlement('academic'|'fees')` — mobile must handle "module not licensed" states (403 variant).

## Explicit non-goals
- No generic proxy/"mobile facade" endpoint bypassing domain boundaries (mission §7). Fan-out composition stays in the client.
- No reuse of any Base44 shape as a reason to reshape ZN APIs.
